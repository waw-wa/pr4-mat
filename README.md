# Практична робота № 4 (7-8): Формула повної ймовірності та формула Байєса в ймовірнісній класифікації та діагностиці програмних систем

Цей репозиторій містить програмну реалізацію, графіки та звіт для практичної роботи № 4 (7-8) з дисципліни «Теорія ймовірностей та математична статистика».

---

## Загальна інформація

* **Дисципліна:** Теорія ймовірностей та математична статистика
* **Тема:** Формула повної ймовірності, формула Байєса та наївний байєсівський класифікатор
* **Варіанти завдань:**
  * **Блок 1:** Загальне завдання (Моделювання байєсівського оновлення ймовірностей)
  * **Блок 2:** Варіант 2 (Точність аналізатора коду SAST)
  * **Блок 3:** Загальне завдання (Наївний байєсівський класифікатор Spam/Ham)
  * **Блок 4:** Варіант 8 (Детекція фроду в платіжному гейтвеї)

---
